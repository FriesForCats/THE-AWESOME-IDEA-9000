# Grocery Surveillance System


## What is the Grocery Surveillance System?
This is a surveillance system designed for grocery stores which is capable of detecting different items as well as people. At its current state it:
- Keeps inventory of all the different items on the camera
- Tracks whether a person has picked up one of those items and adds it to their cart
- Un-ads an item from a persons carts if they put it back down in the camera frame, and re-adds it the shelves inventory
